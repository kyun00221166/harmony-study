# 화성학 스터디 · 베이스

출퇴근길에 폰으로 하는 베이스 연주자용 화성학 공부 앱. 음 이름은 ABC 표기.

- 서버 없음: 정적 파일만 (GitHub Pages)
- 오프라인 동작 (Service Worker), 홈 화면에 추가하면 앱처럼 실행
- 진도는 폰 브라우저 localStorage에 저장

## 현재 내용 (MVP)
1. 음 이름과 지판: 개념 카드 8장 + 퀴즈 4종
2. 음정: 개념 카드 8장 + 지판 모양 퀴즈 2종 + 귀 훈련 2종

틀린 문제는 라이트너 박스 방식으로 더 자주 나옵니다.

## 로컬 실행
아무 정적 서버로 폴더를 열면 됩니다. 예: `npx serve .`
